# MERN Task Manager

A simple MERN stack task management application.

## Features

- Create tasks
- Update task completion
- Delete tasks
- MongoDB database integration

## Tech Stack

- MongoDB
- Express.js
- React.js
- Node.js

## Setup

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm start
```

Create a `.env` file inside backend using `.env.example`.
